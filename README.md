# คลังคำ Finish the Word

เว็บ (PWA) สำหรับหาคำภาษาอังกฤษและอินโดนีเซียไว้เล่นเกม **Finish the Word** ใน Roblox: เกมต่อคำที่ต้องตอบคำที่ขึ้นต้นด้วยตัวอักษรสุดท้ายของคำก่อนหน้า

- เลือกภาษาได้: **อังกฤษ**, **อินโดนีเซีย** หรือ **ทั้งสองภาษา** (รวม 350,284 คำ)
- อินโดนีเซีย 78,697 คำ: คำทั่วไป 49,346 คำ (มีใน KBBI) ที่เหลืออยู่ระดับคำยาก
- อังกฤษ 277,028 คำ แบ่ง 3 ระดับ: **คำทั่วไป** 63,341 คำ (ค่าเริ่มต้น), **+ คำยาก** 115,232 คำ, **ทุกคำ** (รวมคำหายาก/ศัพท์เทคนิค)
- ตัวอักษรที่มีคำทั่วไปน้อย (เช่น X มี 10 คำ) จะมีปุ่มให้ดูคำระดับถัดไปได้ทันที
- ปุ่ม **✗ ไม่รับ** ซ่อนคำที่เกมไม่รับไว้ถาวร และ **✓ ใช้แล้ว** จำว่าเกมรับคำนั้น (ขึ้นก่อนเสมอ) เก็บในเบราว์เซอร์
- ช่องค้นหาแนะนำคำขณะพิมพ์ · ค้นแบบขึ้นต้น / ลงท้าย / มีตัวนี้อยู่
- เรียงตามคำที่ใช้บ่อย, ความยาว หรือ "คำกับดัก" (ลงท้ายด้วยตัวที่คู่แข่งต่อยาก)
- ทำเครื่องหมายคำที่ใช้แล้วในรอบนี้ · เพิ่มคำเองได้ (เก็บในเบราว์เซอร์)
- ติดตั้งลงหน้าจอโฮมได้ (iPhone: Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม) และใช้ได้แม้ไม่มีเน็ต

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (HTML + CSS + JS ในไฟล์เดียว ไม่ต้อง build) |
| `words-id.txt` | คลังคำอินโดนีเซีย รูปแบบเดียวกับ `words.txt`: ระดับ 1 = ใช้บ่อย, 2 = มีใน KBBI, 5 = ไม่มีใน KBBI (ชื่อเฉพาะ ชื่อวิทยาศาสตร์ ฯลฯ) |
| `words.txt` | คลังคำอังกฤษ: คำยอดนิยมเรียงตามความนิยม, บรรทัด `#`, แล้วคำทั้งหมด A→Z; ตัวเลขท้ายคำคือระดับ (1–3 คำทั่วไป = SCOWL ≤50, 4–5 คำยาก = SCOWL 55–70, ไม่มีตัวเลข = หายาก) |
| `sw.js` | service worker เก็บหน้าเว็บและคลังคำไว้ใช้ offline |
| `manifest.webmanifest`, `icons/` | ข้อมูลแอป PWA และไอคอน |
| `vercel.json` | header ของ Vercel (ไม่ cache `sw.js`, content type ของ manifest) |

เมื่อแก้ `index.html` หรือ `words.txt` ให้เปลี่ยน `VERSION` ใน `sw.js` ด้วย เครื่องที่ติดตั้งไว้จะได้โหลดของใหม่

## Deploy บน Vercel

เป็นเว็บ static ล้วน: ใน Vercel กด **Add New → Project → Import** repo นี้ ตั้ง Framework Preset เป็น **Other** ไม่ต้องใส่ Build Command แล้วกด Deploy

## ทดสอบในเครื่อง

```sh
python3 -m http.server 8000   # แล้วเปิด http://localhost:8000
```

## ที่มาของคำ

**อินโดนีเซีย:** คำจาก [Indonesian wordlist](https://github.com/geovedi/indonesian-wordlist) (public domain) จัดระดับ "คำทั่วไป" ด้วยการเทียบกับรายการคำใน KBBI โดยไม่ได้นำรายการ KBBI หรือความหมายมาเผยแพร่ ลำดับความนิยมจากความถี่คำใน Kompas และ Wikipedia ภาษาอินโดนีเซีย ([freq-dist-id](https://github.com/ardwort/freq-dist-id))

**อังกฤษ:** 
คำจาก [word-list](https://github.com/words/an-array-of-english-words) (MIT) และ [SCOWL](http://wordlist.aspell.net/) ผ่าน [wordlist-english](https://github.com/jacksonrayhamilton/wordlist-english) (ใช้ระดับความยาก) ลำดับความนิยมจาก [google-10000-english](https://github.com/first20hours/google-10000-english) เกมไม่เปิดเผยรายการคำที่รับ คำบางคำจึงอาจใช้ไม่ได้
